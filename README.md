# 🎵 PitchTutor - 音準練唱與排練工作台

> 一個現代化、純前端、輕量高效的聲樂練唱、看譜抄譜與音準即時分析工具。

---

## ✨ 核心特色

### 1. 🎼 五線譜看譜 & 首調簡譜雙輸入模式
* **五線譜看譜模式（固定音名 C D E F G A B）**：看五線譜直接按鍵（1~7 或 字母 C~B），系統自動套用調號升降記號（如 3♭ E♭ 大調下輸入 E/3 自動生成 E♭4、A/6 自動生成 A♭4）。
* **首調簡譜模式（1~7 度數即唱名）**：符合簡譜抄譜思維（1=do, 2=re, 3=mi...）。
* **動態按鍵標籤**：鍵盤與面板按鍵即時依據當前調號動態標註音名與升降號。

### 2. 🎹 連音長音發聲引擎（Legato / Sustain）& 4 種高品質合成音色
* **真實時值連貫發聲**：根據歌曲 BPM 與音符時值（全音符、二分音符、四分音符等）精準計算發聲時長，全曲播放無縫連音（Legato）。
* **休止符靜音**：遇到休止符立即平滑靜音，符合真實演奏聽感。
* **4 種音色隨心切換**：
  * 🎹 **鋼琴 (Piano)**：雙諧波振盪器與溫暖觸鍵包絡。
  * 🪈 **長笛管樂 (Flute)**：純淨平穩長音，極適合視唱練唱抓音準。
  * 🎻 **溫暖弦樂 (Strings)**：鋸齒波 + 8 cents 微失諧共振濾波。
  * 🎤 **人聲導唱 (Vocal Ahh)**：雙共振峰帶通濾波器模擬人聲導唱。

### 3. 🎯 麥克風即時音準分析與練唱打分
* 採用高精度自相關算法（Autocorrelation），即時偵測麥克風輸入音高與音準偏差（Cents）。
* 提供單音學習、單音收音、全曲試聽、全曲跟唱等四大模式與成績報告。

### 4. 📝 智能樂譜排版與歌詞對齊
* 小節拍數自動計算，超拍即時警示。
* 支援批次歌詞貼上並自動對齊音符。
* 參考樂譜圖片對照窗格（支援縮放與寬度拖曳）。
* 支援樂譜 JSON 匯出與匯入備份。

## ⌨️ 鍵盤快捷鍵

| 按鍵 | 功能 |
| :--- | :--- |
| **0 ~ 7** | 輸入休止符 (0) 或音符 (1~7) |
| **C ~ B** | 固定音名快捷鍵輸入 |
| **Q / E / S** | 四分音符 / 八分音符 / 十六分音符 |
| **- / +** | 降低八度 / 提高八度 |
| **Backspace** | 刪除游標前一個音符 |
| **Ctrl + Z / Ctrl + Y** | 復原 (Undo) / 重做 (Redo) |
